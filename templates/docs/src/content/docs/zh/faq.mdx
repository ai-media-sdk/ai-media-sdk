# 常见问题

> 模板示例文档，请替换为真实内容。本页刻意只有中文版本：切换到英文后，
> 侧边栏不再列出本页，直接访问英文 URL 会渲染"翻译进行中"占位页。

## 如何新增一种语言？

在 `src/lib/site-config.ts` 的 `SUPPORTED_LANGS` 中加入语言代码，创建
`src/content/docs/<lang>/` 内容目录与 `src/locales/<lang>.json` 字典，
并在 i18n 初始化处注册字典。

## 如何注入业务组件？

在文档页的 MDX 元素映射处合并自定义组件（见 README 的"扩展点"一节），
即可在 MDX 正文中直接使用，例如数据驱动的表格或图表。

## 草稿页如何工作？

frontmatter 标记 `draft: true` 的文档不会出现在导航与翻页中，直接访问
渲染"编写进行中"占位页——参见示例草稿页 roadmap。
