# 快速开始

> 模板示例文档，请替换为真实内容。本页同时演示代码块、表格与引用块的渲染。

## 运行模板

在仓库根目录安装依赖后启动模板开发服务：

```bash
bun install
bun run --cwd templates/docs dev
```

打开 `http://localhost:5175`，根路径会自动重定向到访客语言的第一篇文档。

## 替换内容

### 1. 修改站点配置

`src/lib/site-config.ts` 集中了站点名、存储 key 前缀与语言集：

```ts
export const SITE_NAME = "Docs Template";
export const SUPPORTED_LANGS = ["zh", "en"] as const;
export const SOURCE_LANG: SiteLang = "zh";
```

### 2. 声明文档结构

在 `src/content/docs/manifest.ts` 中按阅读顺序声明分组与 slug，
然后在 `src/content/docs/<lang>/` 下创建同名 MDX 文件：

```mdx
---
title: 页面标题
description: 用于 meta description 的一句话摘要。
---

# 页面标题

正文支持 **Markdown** 与组件。
```

### 3. 校验一致性

```bash
bun run --cwd templates/docs test
```

测试会校验 manifest 与源语言文件双向一致、其他语言无游离文件、
frontmatter 全部合法。

## 部署

构建产物在 `dist/`，`404.html` 深链回退自动生成。部署到 GitHub Pages
子路径时设置 base：

```bash
VITE_SITE_BASE=/my-repo/ bun run --cwd templates/docs build
```

| 场景 | base 设置 |
| --- | --- |
| 根路径 / 自定义域名 | 不设置（默认 `/`） |
| GitHub Pages 项目站 | `VITE_SITE_BASE=/<repo>/` |
